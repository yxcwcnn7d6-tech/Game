iOS Shortcut: Bildanalys med Anthropic Claude (OSH-rapport)
=============================================================

ÖVERSIKT
--------
Denna shortcut tar en bild (kamera eller bildbibliotek), skickar den
till Anthropic Claude Vision API, och visar en OSH-rapport.

FÖRUTSÄTTNINGAR
---------------
- Anthropic API-nyckel (börjar med "sk-ant-...")
- iOS 16+ eller iPadOS 16+
- Appen "Genvägar" (Shortcuts)


VARFÖR "TEXT"-BLOCKET INTE FUNGERAR MED JSON
=============================================
iOS Shortcuts "Text"-action har problem med:
  1. \n-tecken tolkas/försvinner
  2. Klammerparenteser {} kan förväxlas med Shortcuts-variabler
  3. Citattecken inuti JSON kan avsluta texten i förtid
  4. Om "Hämta innehåll på URL" har Request Body satt till "JSON"
     så parsar iOS om texten och förstör strukturen

Lösningen nedan undviker alla dessa problem.


STEG-FÖR-STEG: BYGG SHORTCUTEN (BEPRÖVAD METOD)
==================================================

STEG 1: Skapa ny genväg
   -> Öppna Genvägar-appen
   -> Tryck + för ny genväg
   -> Namnge den t.ex. "OSH Rapport"


STEG 2: Ta foto
   -> Lägg till åtgärd: "Take Photo" (Ta foto)
   -> "Show Camera Preview": PÅ


STEG 3: Ändra storlek (minskar API-kostnad och förhindrar 413-fel)
   -> Lägg till: "Resize Image" (Ändra storlek på bild)
   -> Input: [Photo]
   -> Width: 1024
   -> Height: Auto


STEG 4: Konvertera till JPEG
   -> Lägg till: "Convert Image" (Konvertera bild)
   -> Input: [Resized Image]
   -> Format: JPEG
   -> Quality: 0.7


STEG 5: Base64-koda bilden
   -> Lägg till: "Base64 Encode" (Koda med Base64)
   -> Input: [Converted Image]
   -> Mode: "Encode"

   Variabeln heter nu [Base64 Encoded]


STEG 6: Skriv prompten (SEPARAT Text-block)
   -> Lägg till: "Text"
   -> Skriv in prompten UTAN \n-tecken, använd riktig text:

Analysera bilden och ge en komplett OSH-rapport for raddningstjansten. OSH = Objekt, Skada, Hot (framkomstrapport). Formatera tydligt enligt: OBJEKT: Beskriv vad som ar inblandat. SKADA: Beskriv synlig eller potentiell skada. HOT: Identifiera risker och faror. Var konkret och anvand raddningstjanstterminologi.

   OBS: Undvik svenska tecken (åäö) i prompten - de kan orsaka
   kodningsproblem. Använd "a" istället för "ä" etc.
   Claude förstår ändå.

   Namnge denna variabel till "MinPrompt" (tryck länge på variabeln
   -> "Rename Variable")


STEG 7: Bygg JSON (två delar + sammansättning)

   Detta är NYCKELN - vi bygger JSON i delar för att undvika
   att Shortcuts förstör formateringen.

   7a. Lägg till: "Text"
       Skriv exakt (EN rad, inga radbrytningar):

{"model":"claude-sonnet-4-20250514","max_tokens":1500,"messages":[{"role":"user","content":[{"type":"image","source":{"type":"base64","media_type":"image/jpeg","data":"

   Namnge denna till "JsonStart"


   7b. Lägg till: "Text"
       Skriv exakt (EN rad):

"}},{"type":"text","text":"

   Namnge denna till "JsonMitt"


   7c. Lägg till: "Text"
       Skriv exakt (EN rad):

"}}]}]}

   Namnge denna till "JsonSlut"


   7d. Sätt ihop allt:
       Lägg till: "Text"
       Skriv (genom att dra in variablerna):

       [JsonStart][Base64 Encoded][JsonMitt][MinPrompt][JsonSlut]

       (Du sätter in variablerna genom att trycka på "Insert Variable"
       eller dra dem från listan ovanför tangentbordet)

   Namnge denna till "FullJson"


STEG 8: Skicka API-anropet
   -> Lägg till: "Get Contents of URL" (Hämta innehåll på URL)
   -> URL: https://api.anthropic.com/v1/messages
   -> Method: POST
   -> Headers - tryck "Add New Header" tre gånger:

      Key: Content-Type         Value: application/json
      Key: x-api-key            Value: sk-ant-DIN-NYCKEL-HÄR
      Key: anthropic-version    Value: 2023-06-01

   -> Request Body: FILE  <--- KRITISKT! Välj "File", INTE "JSON"!
   -> File: [FullJson]

   Om du inte ser "File" som alternativ:
   -> Välj "Form" först, sedan byt till "File"


STEG 9: Extrahera svaret
   -> Lägg till: "Get Dictionary Value" (Hämta ordlistevärde)
   -> Input: [Contents of URL]
   -> Key: content

   -> Lägg till: "Get Item from List" (Hämta objekt från lista)
   -> Input: [Dictionary Value]
   -> Get: "First Item"

   -> Lägg till: "Get Dictionary Value" (Hämta ordlistevärde)
   -> Input: [Item from List]
   -> Key: text


STEG 10: Visa resultatet
   -> Lägg till: "Show Result" (Visa resultat)
   -> Input: [Dictionary Value]

   (Valfritt) Kopiera till urklipp:
   -> Lägg till: "Copy to Clipboard"
   -> Input: [Dictionary Value]


ALTERNATIV VARIANT: MED VALFRI PROMPT
======================================
Om du vill kunna skriva en egen fråga varje gång:

Ersätt STEG 6 med:
   -> Lägg till: "Ask for Input" (Be om indata)
   -> Fråga: "Vad vill du veta om bilden?"
   -> Input Type: Text
   -> Default Answer: "Beskriv vad du ser i bilden"

   Använd sedan [Provided Input] istället för [MinPrompt]
   i Steg 7d.


BONUS: SHARE SHEET (skicka bild från valfri app)
==================================================
1. Tryck på shortcutens namn högst upp
2. Välj "Details" / "Detaljer"
3. Sätt PÅ "Show in Share Sheet"
4. Under "Share Sheet Types" välj bara "Images"
5. Ändra Steg 2: Ta bort "Take Photo"
6. Lägg till: "Shortcut Input" (Genvägens indata)
7. Använd [Shortcut Input] som input till Steg 3


FELSÖKNING
==========
Problem: "The request body is not valid JSON"
  -> Kontrollera att FullJson-texten inte har osynliga radbrytningar
  -> Se till att Request Body är "File", INTE "JSON"
  -> Testa: Lägg till "Quick Look" på [FullJson] för att inspektera

Problem: "Request Entity Too Large" / 413-fel
  -> Bilden är för stor. Sänk kvaliteten eller minska storleken mer.

Problem: "Invalid API Key" / 401-fel
  -> Kontrollera att x-api-key headern har rätt nyckel utan mellanslag.
  -> Se till att det inte blev ett extra mellanslag i början/slutet.

Problem: "Could not convert to expected type"
  -> Request Body MÅSTE vara "File", inte "JSON" eller "Form"

Problem: Svaret visar bara "content" eller ser konstigt ut
  -> Du har missat ett "Get Dictionary Value"-steg.
  -> Kedjan ska vara: content -> First Item -> text

Problem: Tomma/konstiga tecken i svaret
  -> Kolla att variablerna i Steg 7d verkligen refererar till rätt
     variabler (tryck på dem för att verifiera).


MODELLVAL
=========
Byt "claude-sonnet-4-20250514" i Steg 7a mot:
  claude-sonnet-4-20250514    Snabb, bra balans (~0.03 kr/bild)
  claude-haiku-3-5-20241022  Snabbast, billigast (~0.005 kr/bild)
  claude-opus-4-20250514    Mest kapabel (~0.15 kr/bild)
