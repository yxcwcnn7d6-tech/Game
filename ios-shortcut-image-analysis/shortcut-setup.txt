iOS Shortcut: Bildanalys med Anthropic Claude (OSH-rapport)
=============================================================

ÖVERSIKT
--------
Denna shortcut tar en bild (kamera eller bildbibliotek), skickar den
till Anthropic Claude Vision API, och visar en OSH-rapport.

Testad och verifierad 2026-02-06.

FÖRUTSÄTTNINGAR
---------------
- Anthropic API-nyckel (börjar med "sk-ant-...")
- iOS 16+ eller iPadOS 16+
- Appen "Genvägar" (Shortcuts)


STEG-FÖR-STEG (BEPRÖVAD METOD)
================================

STEG 1: Skapa ny genväg
   -> Öppna Genvägar-appen
   -> Tryck + för ny genväg
   -> Namnge den t.ex. "OSH Rapport"


STEG 2: Ta foto
   -> Lägg till: "Take Photo"
   -> "Show Camera Preview": PÅ


STEG 3: Ändra storlek (minskar kostnad, förhindrar 413-fel)
   -> Lägg till: "Resize Image"
   -> Input: [Photo]
   -> Width: 1024
   -> Height: Auto


STEG 4: Konvertera till JPEG
   -> Lägg till: "Convert Image"
   -> Input: [Resized Image]
   -> Format: JPEG
   -> Quality: 0.7


STEG 5: Base64-koda
   -> Lägg till: "Base64 Encode"
   -> Input: [Converted Image]
   -> Mode: "Encode"


STEG 6: Rensa radbrytningar ur base64 (KRITISKT!)
   -> Lägg till: "Replace Text"
   -> Find: [\r\n]
   -> Replace with: (LÄMNA HELT TOMT - skriv ingenting!)
   -> In: [Base64 Encoded]
   -> Tryck på pilen (>) och sätt "Regular Expression": PÅ

   iOS Base64 Encode lägger in radbrytningar var 76:e tecken.
   Dessa förstör JSON:en om de inte tas bort.


STEG 7: JSON med prompt (ETT Text-block)
   -> Lägg till: "Text"
   -> Klistra in exakt (EN rad, inga radbrytningar):

{"model":"claude-sonnet-4-20250514","max_tokens":300,"messages":[{"role":"user","content":[{"type":"image","source":{"type":"base64","media_type":"image/jpeg","data":"IMGDATA"}},{"type":"text","text":"Du ar en svensk raddningstjanst-operator. Ge en kort OSH-rapport (Objekt, Skada, Hot) for bilden. OSH ar INTE Occupational Safety and Health. Det ar raddningstjanstens snabbformat: Objekt = vad det ar (typ av byggnad, fordon etc, kort), Skada = vad som hant med objektet (t.ex. overtand, vattensakda, deformerat), Hot = risker (t.ex. spridning, personskador, ras). Var extremt kortfattad, max 1-2 meningar per punkt. Exempel: Objekt: 2 vanings trabyggnad. Skada: overtand. Hot: risk for spridning, okant om personskador. Svara BARA med de tre punkterna, ingen inledning eller avslutning."}]}]}


STEG 8: Ersätt placeholder med riktig base64
   -> Lägg till: "Replace Text"
   -> Find: IMGDATA
   -> Replace with: [Updated Text] (output från Steg 6)
   -> Regular Expression: AV


STEG 9: Skicka API-anrop
   -> Lägg till: "Get Contents of URL"
   -> URL: https://api.anthropic.com/v1/messages
   -> Method: POST
   -> Headers (lägg till 3 st):
      Content-Type      : application/json
      x-api-key         : sk-ant-DIN-NYCKEL-HÄR
      anthropic-version : 2023-06-01

   -> Request Body: FILE   <--- KRITISKT! Inte "JSON"!
   -> File: [Updated Text] (output från Steg 8)


STEG 10: Extrahera svaret
   -> Lägg till: "Get Dictionary Value"
   -> Key: content
   -> In: [Contents of URL]

   -> Lägg till: "Get Item from List"
   -> Get: "First Item"
   -> From: [Dictionary Value]

   -> Lägg till: "Get Dictionary Value"
   -> Key: text
   -> In: [Item from List]


STEG 11: Visa resultatet
   -> Lägg till: "Show Result"
   -> Input: [Dictionary Value]

   (Valfritt) Kopiera till urklipp:
   -> Lägg till: "Copy to Clipboard"
   -> Input: [Dictionary Value]


SAMMANFATTNING AV ACTIONS (12 st)
===================================
 1. Take Photo
 2. Resize Image (1024 x Auto)
 3. Convert Image (JPEG, 0.7)
 4. Base64 Encode
 5. Replace Text: [\r\n] -> (tomt), Regex PÅ
 6. Text: JSON med IMGDATA placeholder
 7. Replace Text: IMGDATA -> [Updated Text], Regex AV
 8. Get Contents of URL (POST, File body)
 9. Get Dictionary Value (key: content)
10. Get Item from List (First Item)
11. Get Dictionary Value (key: text)
12. Show Result


VIKTIGA FALLGROPAR
==================
1. Request Body MÅSTE vara "File", inte "JSON" eller "Form"
2. Base64-radbrytningar MÅSTE rensas (Steg 6), annars "invalid JSON"
3. Regex i Steg 6 MÅSTE vara PÅ, i Steg 8 MÅSTE vara AV
4. Replace-fältet i Steg 6 MÅSTE vara helt tomt (inte "World", " ", etc.)
5. API-nyckeln visas bara i sin helhet vid skapande - kopiera direkt!


ANPASSA PROMPTEN
================
Ändra texten efter "text":" i Steg 7 JSON:en.
Undvik \n, citattecken (") och åäö i prompten.
Claude förstår "a" istället för "ä" osv.

Exempelprompts:
  "Beskriv vad du ser i bilden"
  "Las av texten i bilden och returnera den"
  "Identifiera alla produkter i bilden"


BONUS: SHARE SHEET
===================
Skicka bilder från valfri app:
1. Tryck på shortcutens namn -> Details
2. Sätt PÅ "Show in Share Sheet"
3. Under "Share Sheet Types" välj bara "Images"
4. Byt "Take Photo" mot "Shortcut Input"


MODELLVAL
=========
Byt "claude-sonnet-4-20250514" i Steg 7 mot:
  claude-sonnet-4-20250514    Snabb, bra balans (~0.03 kr/bild)
  claude-haiku-3-5-20241022  Snabbast, billigast (~0.005 kr/bild)
  claude-opus-4-20250514    Mest kapabel (~0.15 kr/bild)
